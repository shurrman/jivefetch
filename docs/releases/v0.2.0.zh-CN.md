# JiveFetch v0.2.0

日期：2026-09-03

此小版本预览将首个可用下载功能扩展为可配置的桌面队列。

## 亮点

- 新的高对比度 JiveFetch 应用图标与完整原生图标集。
- 顶部紧凑设置区包含语言、跟随系统/深色/浅色主题、输出目录、并发数和全局速度预算。
- 并发预设为 1 到 10，也可输入最大 64 的有效自定义值；首次运行默认值为 2。
- 提供 512 KB/s、1 MB/s、2 MB/s、3 MB/s、不限速和自定义 KB/s。scheduler 会在配置的
  槽位之间分配全局预算，从设计上保证并行 attempt 不超过所选总上限。
- 设置经 migration 后保存在 SQLite。变更应用于新的 attempt；降低并发数不会终止
  JiveFetch 已拥有的运行中任务。
- 队列 snapshot 每五秒刷新，并为每个任务显示彩色进度条、状态、已下载/总大小、速度和 ETA。
- `yt-dlp` 与 FFmpeg 版本直接显示在顶部，不再使用面向实现细节的卡片。
- macOS、Linux 与 Windows 使用原生目录选择器；默认仍为 `Downloads/JiveFetch`。
- 可选从 Brave、Chrome、Chromium、Edge、Firefox、Opera、Safari、Vivaldi 与 Whale
  读取 Cookie，通过类型化 `yt-dlp --cookies-from-browser` 参数实现。JiveFetch 只保存
  浏览器标识，不保存 Cookie 值。

## 兼容性与限制

此预览版仍调用本机安装的 `yt-dlp` 和 FFmpeg。软件包尚未签名或 notarize，也未包含
managed sidecar。请参阅
[打包限制](https://github.com/shurrman/jivefetch/blob/v0.2.0/docs/packaging.zh-CN.md)
与[安全模型](https://github.com/shurrman/jivefetch/blob/v0.2.0/docs/security.zh-CN.md)。

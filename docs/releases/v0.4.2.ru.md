# JiveFetch v0.4.2

Дата: 2026-09-06

Этот релиз добавляет явный безопасный выбор: удалить только задачу из очереди или также
удалить связанные с ней файлы загрузки.

## Главное

- «Удалить» открывает локализованный нативный вопрос «Да/Нет»: сохранить файлы либо
  удалить с диска проверенный итоговый файл и partial-файлы под управлением JiveFetch.
- Новые задачи хранят resumable temporary data в task-owned workspace, сохраняя обычное
  пользовательское имя итогового файла.
- Rust получает цели удаления по task ID и revision. Webview не передаёт filesystem paths,
  и никакие filename globs не раскрываются.
- Canonical path checks не позволяют удалить данные вне выбранной output directory.
  Общие final files сохраняются, а при ошибке очистки задача остаётся доступна для повтора.
- Существующие задачи сохраняют legacy layout и resumability. Их записанный final file
  можно удалить; неизвестные legacy partials не угадываются по похожим именам.

## Проверка

- Migration SQLite schema version 7 сохраняет существующую очередь и оставляет legacy
  artifact keys равными null.
- Обычный Rust suite вырос с 28 до 34 тестов плюс opt-in real-engine smoke.
- Release gates включают форматирование, Clippy с запретом warnings, все Rust targets,
  frontend build/typecheck, 21 комплект трёхъязычной документации, anchors и secret scan.

## Установка на macOS

DMG для macOS по-прежнему не подписан и не notarized. Сначала проверьте checksum, затем
выполните [инструкцию установки на macOS](../macos-installation.ru.md).

## Совместимость и ограничения

Этот unsigned release использует локально установленные `yt-dlp`, FFmpeg и Deno. Managed
sidecars, production signing/notarization, SBOM/provenance и clean-machine release tests
ещё не готовы. См. [ограничения упаковки](../packaging.ru.md) и
[модель безопасности](../security.ru.md).

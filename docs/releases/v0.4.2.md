# JiveFetch v0.4.2

Date: 2026-09-06

This release adds an explicit, safe choice between removing only a queue item and also
deleting its associated download files.

## Highlights

- Remove opens a localized native Yes/No question: keep files, or delete the verified
  final output and JiveFetch-managed partial files from disk.
- New tasks keep resumable temporary data in a task-owned workspace while retaining the
  normal user-facing filename for the final output.
- Rust resolves deletion targets from the task ID and revision. The webview never supplies
  filesystem paths, and no filename glob is expanded.
- Canonical path checks prevent deletion outside the selected output directory. Shared
  final files are retained, and a failed cleanup leaves the queue item available to retry.
- Existing tasks keep their legacy layout and resumability. Their recorded final file can
  be deleted; unknown legacy partials are not guessed from similar filenames.

## Validation

- SQLite schema version 7 migration preserves existing queues and leaves legacy artifact
  keys null.
- The regular Rust suite grows from 28 to 34 tests, plus the opt-in real-engine smoke.
- Formatting, Clippy with warnings denied, all Rust targets, frontend build/type checking,
  21 multilingual documentation sets, release anchors, and secret scanning are release gates.

## Install on macOS

The macOS DMG remains unsigned and unnotarized. Verify its checksum first, then follow
the [macOS installation instructions](../macos-installation.md).

## Compatibility and limits

This unsigned release uses locally installed `yt-dlp`, FFmpeg, and Deno. Managed sidecars,
production signing/notarization, SBOM/provenance, and clean-machine release testing are
not complete. See the [packaging limits](../packaging.md) and [security model](../security.md).

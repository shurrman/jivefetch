# JiveFetch v0.3.0

日期：2026-09-03

此小版本预览加入真实来源格式选择，并使队列状态可信。

## 亮点

- URL 可在加入前检查，并从 `yt-dlp` 实际报告的视频格式中选择，显示分辨率、FPS、
  编解码器、容器、来源码率和估算大小。没有大小估算的重复标题式行与内部格式 ID
  不向用户显示；默认仍为最高可用质量。
- 右键点击队列任务可选择启动、停止、暂停、复制 URL 和移除。当前持久状态不允许的
  操作仍会显示，但处于禁用状态。
- 队列显示会保留非秘密 URL 查询参数，因此 YouTube 视频 ID 和其他 extractor 关键值
  不再隐藏；看起来像秘密的值会被脱敏。
- 即使最终路径输出会启用 quiet 行为，也会显式打开 `yt-dlp` progress 输出，从而恢复
  当前字节、总大小、速度、ETA 与进度条更新。
- 任务完成前会验证最终 artifact 是所选输出目录内的非空普通文件，然后保存实际大小。
- 启动时根据已验证输出文件修复旧 completed 任务的零字节指标，无需重新下载。
- 快速版本进程退出后会等待输出排空，避免桌面冷启动时偶发错误显示“未找到 yt-dlp”。
- 所选格式持久保存在 SQLite 队列中，并仅以经过验证的类型化 selector 传给 `yt-dlp`；
  不执行来自 UI 的 shell command。

## 在 macOS 上安装

Apple Silicon DMG 仍未签名且未 notarize。首次启动前，请按先验证 checksum 的
[macOS 安装说明](https://github.com/shurrman/jivefetch/blob/main/docs/macos-installation.zh-CN.md)操作。

## 兼容性与限制

此预览版调用本机安装的 `yt-dlp` 和 FFmpeg。软件包尚未签名或 notarize，也未包含
managed sidecar。请参阅
[打包限制](https://github.com/shurrman/jivefetch/blob/v0.3.0/docs/packaging.zh-CN.md)
与[安全模型](https://github.com/shurrman/jivefetch/blob/v0.3.0/docs/security.zh-CN.md)。

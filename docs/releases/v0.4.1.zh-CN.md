# JiveFetch v0.4.1

日期：2026-09-06

此维护版本让 Resume 状态在 `yt-dlp` 重新连接现有 partial 下载期间保持真实。

## 亮点

- 预留新的继续 attempt 时，继续显示最后确认的整体 progress、已下载大小与总大小估算。
- 收到新的引擎 progress 前，显示本地化的“正在准备继续下载”阶段。
- 每个继续组件首次观察到的 byte 位置作为 baseline，之后只把新增量加入 checkpoint，
  从而避免可见的 0% 回退与 partial bytes 重复计算。
- Completion 契约保持不变：活动任务低于 100%；只有经过验证的非空最终文件才达到
  100% 并启用“打开”。

## 验证

- 常规 Rust 测试从 26 增加到 28 个，覆盖 durable checkpoint 保留与 Resume 后的多组件聚合。
- SQLite 保持 schema version 6；无需迁移现有队列。
- Release gate 包含格式化、禁止 warning 的 Clippy、全部 Rust targets、opt-in real-engine
  smoke、frontend build/typecheck、三语文档、release-note anchor 与 secret scan。

[打包限制](../packaging.zh-CN.md)和[安全模型](../security.zh-CN.md)。

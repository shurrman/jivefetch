# JiveFetch v0.1.1

## Статус

Это первый функциональный кроссплатформенный preview. Он заменяет неопубликованный
candidate `v0.1.0`, явно задавая native bundle icons для каждой платформы. Artifacts
не подписаны, а macOS-пакет не notarized, поэтому это ещё не production-stable релиз.

## Главное

- Устойчивая Rust/SQLite-очередь с восстановлением после запуска.
- Реальный запуск `yt-dlp` и проверка capabilities FFmpeg.
- Supervisor собственного дерева процессов с переносимыми Pause, Resume и Stop.
- UI и документация на EN/RU/简体中文; английский по умолчанию.
- Native DMG, AppImage/deb и NSIS/MSI с SHA-256 checksums.

## Требования

JiveFetch 0.1.1 использует локально установленные `yt-dlp` и FFmpeg и не распространяет
эти движки. Перед установкой см. [ограничения упаковки](../packaging.ru.md).

## Известные ограничения

- Пакеты не подписаны, macOS DMG не notarized.
- Linux dependency chain Tauri/GTK содержит `GHSA-wrw7-89jp-8q8g`; JiveFetch не
  использует затронутый API, но advisory должен быть устранён до stable-релиза.

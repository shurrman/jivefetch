# JiveFetch v0.3.1

Дата: 2026-09-05

Этот maintenance-релиз делает обнаружение desktop-движков и авторизованные загрузки
YouTube надёжными, а общие ошибки заменяет полезными объяснениями.

## Главное

- Версия JiveFetch показывается рядом с обнаруженными версиями `yt-dlp` и FFmpeg.
- Версии движков проверяются из app-data, а не из защищённой папки Downloads: macOS race
  разрешений больше не должен ошибочно показывать отсутствие Homebrew `yt-dlp`.
- Сохраняется минимальное кроссплатформенное окружение дочернего процесса, но в `PATH`
  добавлены стандартные каталоги пакетных менеджеров и пользовательский каталог Deno.
  Запущенная из Finder JiveFetch теперь передаёт Homebrew Deno в `yt-dlp` для актуальных
  JavaScript challenge YouTube.
- Ошибки browser cookies, авторизации, недоступного медиа, rate limit, HTTP 403, формата,
  сети и файловой системы классифицируются без сохранения сырого вывода и signed URL.
- После выхода процесса дочитывается финальный вывод, поэтому короткие ошибки не теряются.
- Установка `yt-dlp`, FFmpeg и Deno на macOS, Windows и Linux документирована на английском,
  русском и упрощённом китайском.
- Объяснено, почему после замены ad-hoc подписанной macOS-сборки может понадобиться заново
  разрешить Downloads или Full Disk Access и когда появляется запрос Chrome Safe Storage.

## Проверенный сценарий macOS

Установленная локальная сборка обнаружила `yt-dlp` 2026.07.04, FFmpeg 8.1.2 и Deno 2.9.4.
При выбранном Chrome `yt-dlp` прочитал cookies браузера, решил JavaScript challenge через
Deno, выбрал медиапотоки, после чего загрузка началась.

## Установка на macOS

DMG для Apple Silicon по-прежнему не подписан и не notarized. Сначала проверьте checksum,
затем выполните [инструкцию установки на macOS](../macos-installation.ru.md).

## Совместимость и ограничения

Релиз использует локально установленные `yt-dlp`, FFmpeg и Deno. Пакеты пока не подписаны
и не notarized; managed sidecars не включены. См. [ограничения упаковки](../packaging.ru.md)
и [модель безопасности](../security.ru.md).

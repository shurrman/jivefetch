# JiveFetch v0.1.0

## Статус

Это первый функциональный кроссплатформенный preview. Native CI собирает artifacts
на macOS, Linux и Windows. Они не подписаны, а macOS-пакет не notarized; это ещё не
production-stable релиз.

## Главное

- Устойчивая Rust/SQLite-очередь с восстановлением после запуска.
- Реальный запуск `yt-dlp` и проверка capabilities FFmpeg.
- Supervisor собственного дерева процессов с переносимыми Pause, Resume и Stop.
- UI и документация на EN/RU/简体中文; английский по умолчанию.
- Лицензия Apache-2.0 и проверки секретов/целостности документов.

## Пакеты

- macOS: DMG.
- Linux: AppImage и deb.
- Windows: NSIS setup executable и MSI.
- Для каждой платформы публикуется файл SHA-256 checksums.

JiveFetch 0.1.0 использует локально установленные `yt-dlp` и FFmpeg и не распространяет
эти движки. Перед установкой см. [ограничения упаковки](../packaging.ru.md).

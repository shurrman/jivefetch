# JiveFetch v0.4.1

Дата: 2026-09-06

Этот maintenance release честно показывает состояние Resume, пока `yt-dlp` подключается
к существующей partial-загрузке.

## Главное

- При reservation новой продолженной попытки сохраняются видимыми последний подтверждённый
  общий progress, загруженный размер и оценка общего размера.
- До появления свежего progress движка показывается локализованный этап «Подготовка к
  продолжению».
- Первая наблюдаемая позиция bytes каждого продолженного компонента становится baseline;
  к checkpoint добавляется только дальнейший прирост. Нет ни видимого отката на 0%, ни
  двойного учёта partial bytes.
- Контракт completion не меняется: активная работа остаётся ниже 100%, и только проверенный
  непустой итоговый файл получает 100% и кнопку «Открыть».

## Проверка

- Обычный Rust suite вырос с 26 до 28 тестов и проверяет durable checkpoint и агрегацию
  нескольких компонентов после Resume.
- SQLite остаётся на schema version 6; migration очереди не требуется.
- Release gates включают форматирование, Clippy с запретом warnings, все Rust targets,
  opt-in real-engine smoke, frontend build/typecheck, трёхъязычную документацию, anchors
  release notes и secret scan.

## Установка на macOS

DMG для macOS по-прежнему не подписан и не notarized. Сначала проверьте checksum, затем
выполните [инструкцию установки на macOS](../macos-installation.ru.md).

## Совместимость и ограничения

Этот pre-release использует локально установленные `yt-dlp`, FFmpeg и Deno. Managed
sidecars, production signing/notarization, SBOM/provenance и clean-machine release tests
ещё не готовы. См. [ограничения упаковки](../packaging.ru.md) и
[модель безопасности](../security.ru.md).

# JiveFetch v0.3.0

Дата: 2026-09-03

Эта минорная preview-версия добавляет выбор реального формата источника и достоверный статус очереди.

## Главное

- URL можно проверить до добавления и выбрать видеоформат из фактически найденных `yt-dlp`:
  показываются разрешение, FPS, кодек, контейнер, битрейт источника и оценка размера.
  Похожие на заголовки строки без оценки размера и внутренние ID движка скрыты от пользователя.
  По умолчанию остаётся максимальное доступное качество.
- Правая кнопка на задаче открывает «Запустить», «Остановить», «Пауза», «Копировать URL»
  и «Удалить». Недопустимые в текущем устойчивом состоянии команды видны, но отключены.
- В очереди сохраняются несекретные query-параметры URL, поэтому ID видео YouTube и другие
  значимые для extractor значения больше не скрыты; похожие на секреты значения маскируются.
- Вывод progress `yt-dlp` включён явно даже при активирующем quiet-режим выводе финального
  пути: снова обновляются текущий и общий размер, скорость, ETA и progress bar.
- Перед завершением проверяется, что artifact — непустой обычный файл внутри выбранной папки;
  затем в SQLite сохраняется его фактический размер.
- При запуске исправляются нулевые метрики старых завершённых задач по проверенным выходным
  файлам без повторного скачивания.
- После выхода быстрого version-процесса приложение дожидается drain вывода, исключая
  случайное ложное «yt-dlp не найден» при чистом desktop-запуске.
- Выбранный формат сохраняется в SQLite-очереди и передаётся `yt-dlp` только как проверенный
  типизированный selector; shell-команды из UI не исполняются.

## Установка на macOS

DMG для Apple Silicon по-прежнему не подписан и не notarized. Перед первым запуском выполните
[инструкцию установки на macOS](https://github.com/shurrman/jivefetch/blob/main/docs/macos-installation.ru.md), начиная с проверки checksum.

## Совместимость и ограничения

Preview использует локально установленные `yt-dlp` и FFmpeg. Пакеты пока не подписаны и не
notarized; managed sidecars не включены. См.
[ограничения упаковки](https://github.com/shurrman/jivefetch/blob/v0.3.0/docs/packaging.ru.md)
и [модель безопасности](https://github.com/shurrman/jivefetch/blob/v0.3.0/docs/security.ru.md).

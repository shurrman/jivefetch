# JiveFetch v0.1.0

## Status

This is the first functional cross-platform preview. Native CI builds the artifacts
on macOS, Linux, and Windows. They are unsigned and, on macOS, not notarized; this is
not yet a production-stable release.

## Highlights

- Persistent Rust/SQLite queue with startup recovery.
- Real `yt-dlp` execution and FFmpeg capability validation.
- Owned process-tree supervision with portable Pause, Resume, and Stop behavior.
- English, Russian, and Simplified Chinese UI and documentation; English by default.
- Apache-2.0 project license and secret/document consistency checks.

## Packages

- macOS: DMG.
- Linux: AppImage and deb.
- Windows: NSIS setup executable and MSI.
- Every platform includes a SHA-256 checksum file.

JiveFetch 0.1.0 uses locally installed `yt-dlp` and FFmpeg and does not redistribute
those engines. See the [packaging limits](../packaging.md) before installation.

## Known limitations

- Packages are unsigned and the macOS DMG is not notarized.
- The Linux Tauri/GTK dependency chain carries `GHSA-wrw7-89jp-8q8g`; JiveFetch does
  not use the affected API, but removing the advisory is required before stable release.

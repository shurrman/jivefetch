# JiveFetch v0.2.0

Date: 2026-09-03

This minor preview turns the initial downloader slice into a configurable desktop queue.

## Highlights

- New high-contrast JiveFetch application icon and complete native icon set.
- Compact top controls for language, system/light/dark theme, output folder, concurrency,
  and a global speed budget.
- Concurrency presets from 1 through 10, plus a validated custom value up to 64; the
  first-run default is 2.
- Speed presets of 512 KB/s, 1 MB/s, 2 MB/s, and 3 MB/s, plus an unlimited mode and a
  custom KB/s value. The scheduler divides the global budget across configured slots so
  simultaneous attempts cannot exceed the selected aggregate ceiling by design.
- Settings are migrated and stored in SQLite. Changes affect new attempts; lowering
  concurrency never kills work already owned by JiveFetch.
- Queue snapshots refresh every five seconds and show a colored progress bar, state,
  downloaded/total size, current speed, and ETA for every task.
- `yt-dlp` and FFmpeg versions are visible in the header without implementation-detail cards.
- Native folder selection on macOS, Linux, and Windows; the default remains
  `Downloads/JiveFetch`.
- Optional browser-cookie authentication for Brave, Chrome, Chromium, Edge, Firefox,
  Opera, Safari, Vivaldi, and Whale through typed `yt-dlp --cookies-from-browser`
  arguments. JiveFetch stores only the browser identifier, never cookie values.

## Compatibility and limits

This preview continues to use locally installed `yt-dlp` and FFmpeg. Packages are not yet
signed or notarized, and managed sidecars are not included. See the
[packaging limits](../packaging.md) and [security model](../security.md).

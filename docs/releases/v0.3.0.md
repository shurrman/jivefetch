# JiveFetch v0.3.0

Date: 2026-09-03

This minor preview adds real source-format selection and makes queue status trustworthy.

## Highlights

- Check a URL before adding it and choose from the video formats actually reported by
  `yt-dlp`, including resolution, FPS, codec, container, source bitrate, and estimated
  size. Duplicate-looking rows without a size estimate and internal engine format IDs are
  hidden from the user. Maximum available quality remains default.
- Right-click a queue task for Start, Stop, Pause, Copy URL, and Remove. Invalid actions
  remain visible but disabled for the task's current durable state.
- Preserve non-secret URL query parameters in the queue display, so YouTube video IDs and
  other extractor-significant values are no longer hidden; secret-looking values are redacted.
- Explicitly enable `yt-dlp` progress output even when final-path printing activates quiet
  behavior, restoring current bytes, total size, speed, ETA, and the progress bar.
- Verify the final artifact is a non-empty regular file inside the selected output directory
  before completing a task, then persist its actual size.
- Repair zero-byte metrics for existing completed tasks from their verified output files on
  startup without downloading them again.
- Drain fast version-process output after exit to prevent intermittent false `yt-dlp not found`
  results during a cold desktop launch.
- Persist the selected format through the SQLite queue and pass only a validated typed
  selector to `yt-dlp`; no UI-provided shell command is executed.

## Install on macOS

The Apple Silicon DMG remains unsigned and unnotarized. Before the first launch, follow the
checksum-first [macOS installation instructions](https://github.com/shurrman/jivefetch/blob/main/docs/macos-installation.md).

## Compatibility and limits

This preview uses locally installed `yt-dlp` and FFmpeg. Packages are not yet signed or
notarized, and managed sidecars are not included. See the
[packaging limits](https://github.com/shurrman/jivefetch/blob/v0.3.0/docs/packaging.md) and
[security model](https://github.com/shurrman/jivefetch/blob/v0.3.0/docs/security.md).

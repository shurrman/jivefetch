# JiveFetch v0.4.1

Date: 2026-09-06

This maintenance release makes Resume status truthful while `yt-dlp` reconnects to an
existing partial download.

## Highlights

- Keep the last confirmed overall progress, downloaded size, and total estimate visible
  when a new resumable attempt is reserved.
- Show a localized Preparing to resume stage until fresh engine progress arrives.
- Treat each resumed component's first observed byte position as a baseline and add only
  later deltas, avoiding both a visible 0% rollback and double-counted partial bytes.
- Preserve the existing completion contract: active work stays below 100%, and only a
  verified non-empty final file reaches 100% and enables Open.

## Validation

- The regular Rust suite grows from 26 to 28 tests and covers durable checkpoint
  preservation plus resumed multi-component aggregation.
- SQLite remains at schema version 6; no queue migration is required.
- Formatting, Clippy with warnings denied, all Rust targets, the opt-in real-engine smoke,
  frontend build/type checking, multilingual documentation, release anchors, and secret
  scanning are release gates.

## Install on macOS

The macOS DMG remains unsigned and unnotarized. Verify its checksum first, then follow
the [macOS installation instructions](../macos-installation.md).

## Compatibility and limits

This pre-release uses locally installed `yt-dlp`, FFmpeg, and Deno. Managed sidecars,
production signing/notarization, SBOM/provenance, and clean-machine release testing are
not complete. See the [packaging limits](../packaging.md) and [security model](../security.md).

# JiveFetch v0.4.0

Дата: 2026-09-05

Этот релиз правдиво показывает ход загрузки отдельных video/audio-потоков, безопасно
открывает завершённые файлы и укрепляет Rust-ядро, не превращая UI во второй источник
состояния.

## Главное

- Один монотонный общий progress задачи объединяет плановые video/audio-компоненты,
  текущий этап, суммарный размер, скорость и ETA. Активная работа остаётся ниже 100%;
  100% появляется только после проверки итогового файла.
- Во время загрузки показываются локализованные этапы «Видео», «Аудио», «Медиа» и
  «Объединение».
- Кнопка «Открыть» доступна только успешно завершённой задаче, чей непустой итоговый файл
  всё ещё находится внутри выбранной папки. Путь получает и проверяет Rust backend.
- Сообщения о локальном контроле и готовности движков объединены в компактной строке
  заголовка; ввод URL, выбор формата и добавление в очередь сохранены.
- Внутренние string errors заменены typed validation/storage/engine/scheduler/input
  errors; стабильные локализованные сообщения формируются только на IPC boundary.
- Binary discovery отделён от engine execution, добавлены узкие test seams движка и
  запуска процессов при сохранении одного scheduler и одного владельца process tree.
- Добавлены ограниченные по размеру structured JSON diagnostics без raw engine lines,
  URL, cookies, browser-profile paths и output paths.

## Проверка

- In-place recovery test проверяет migration SQLite schema с версии 5 на 6.
- Обычный Rust suite вырос с 22 до 26 тестов; отдельно проходит opt-in real-engine smoke.
- Release gates проверяют форматирование, Clippy с запретом warnings, frontend typecheck и
  build, ссылки трёхъязычной документации, anchors release notes и отсутствие секретов.

## Установка на macOS

DMG для macOS по-прежнему не подписан и не notarized. Сначала проверьте checksum, затем
выполните [инструкцию установки на macOS](../macos-installation.ru.md).

## Совместимость и ограничения

Этот pre-release использует локально установленные `yt-dlp`, FFmpeg и Deno. Managed
sidecars, production signing/notarization, SBOM/provenance и clean-machine release tests
ещё не готовы. См. [ограничения упаковки](../packaging.ru.md) и
[модель безопасности](../security.ru.md).

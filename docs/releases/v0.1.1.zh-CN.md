# JiveFetch v0.1.1

## 状态

这是首个可用的跨平台预览版。它取代未发布的 `v0.1.0` candidate，并为每个平台明确
配置 native bundle icon。Artifact 未签名，macOS 包也未 notarize，因此尚不是
production-stable 版本。

## 主要功能

- 可在启动后恢复的 Rust/SQLite 持久队列。
- 真实执行 `yt-dlp` 并验证 FFmpeg capability。
- 仅监管所属进程树，并提供跨平台暂停、继续和停止语义。
- EN/RU/简体中文 UI 与文档，首次运行默认英语。
- Native DMG、AppImage/deb 和 NSIS/MSI，并提供 SHA-256 checksum。

## 要求

JiveFetch 0.1.1 使用本机安装的 `yt-dlp` 和 FFmpeg，不再分发这些引擎。安装前请阅读
[打包限制](../packaging.zh-CN.md)。

## 已知限制

- 软件包未签名，macOS DMG 未 notarize。
- Linux Tauri/GTK dependency chain 包含 `GHSA-wrw7-89jp-8q8g`；JiveFetch 不使用
  受影响 API，但 stable release 前必须消除此 advisory。

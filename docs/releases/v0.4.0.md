# JiveFetch v0.4.0

Date: 2026-09-05

This release makes download progress truthful across separate video and audio streams,
adds safe opening of completed files, and strengthens the Rust core without turning the
UI into a second source of state.

## Highlights

- Show one monotonic task-wide progress value across planned video and audio components,
  with current stage, aggregate size, speed, and ETA. Active work stays below 100%; only
  a verified final file reaches 100%.
- Show localized Video, Audio, Media, and Merging stages while a task is running.
- Offer Open only for a successfully completed task whose non-empty output still exists
  inside the configured download folder. The Rust backend resolves and validates the path.
- Move the local-control and engine-ready message into one compact header line while
  retaining the URL input, format picker, and Add to queue controls.
- Replace internal string errors with typed validation, storage, engine, scheduler, and
  input errors, mapped to stable localized messages only at the IPC boundary.
- Separate binary discovery from engine execution and add narrow test seams for engine
  and process spawning while retaining one scheduler and one process-tree owner.
- Add bounded structured JSON diagnostics without raw engine lines, URLs, cookies,
  browser-profile paths, or output paths.

## Validation

- SQLite schema migration from version 5 to 6 is covered by an in-place recovery test.
- The regular Rust suite grows from 22 to 26 tests, plus an opt-in real-engine smoke test.
- Formatting, Clippy with warnings denied, frontend type checking/build, multilingual
  documentation links, release-note anchors, and secret scanning are release gates.

## Install on macOS

The macOS DMG remains unsigned and unnotarized. Verify its checksum first, then follow
the [macOS installation instructions](../macos-installation.md).

## Compatibility and limits

This pre-release uses locally installed `yt-dlp`, FFmpeg, and Deno. Managed sidecars,
production signing/notarization, SBOM/provenance, and clean-machine release testing are
not complete. See the [packaging limits](../packaging.md) and [security model](../security.md).

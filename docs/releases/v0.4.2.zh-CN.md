# JiveFetch v0.4.2

日期：2026-09-06

此版本新增明确且安全的选择：只移除队列任务，或同时删除与其关联的下载文件。

## 亮点

- “移除”会打开本地化原生“是/否”问题：保留文件，或从磁盘删除已验证最终输出和
  JiveFetch 管理的 partial 文件。
- 新任务把 resumable temporary data 保存在 task-owned workspace，同时保留普通的
  用户可见最终文件名。
- Rust 根据 task ID 与 revision 解析删除目标；webview 不传 filesystem path，也不展开
  任何 filename glob。
- Canonical path 检查阻止删除所选 output directory 之外的数据。共享 final file 会被
  保留；清理失败时任务仍可见，可再次尝试。
- 现有任务保留 legacy layout 与 resumability。可以删除其已记录 final file，但不会按
  相似文件名猜测未知 legacy partial。

## 验证

- SQLite schema version 7 migration 会保留现有队列，并让 legacy artifact key 保持 null。
- 常规 Rust 测试从 28 增加到 34 个，另有 opt-in 真实引擎 smoke。
- Release gate 包含格式化、禁止 warning 的 Clippy、全部 Rust targets、frontend
  build/typecheck、21 组三语文档、release anchor 与 secret scan。

## 在 macOS 上安装

macOS DMG 仍未签名且未 notarize。请先验证 checksum，再按照
[macOS 安装说明](../macos-installation.zh-CN.md)操作。

## 兼容性与限制

此 unsigned release 使用本机安装的 `yt-dlp`、FFmpeg 与 Deno。Managed sidecar、
production signing/notarization、SBOM/provenance 与 clean-machine release test 尚未完成。
请参阅[打包限制](../packaging.zh-CN.md)和[安全模型](../security.zh-CN.md)。

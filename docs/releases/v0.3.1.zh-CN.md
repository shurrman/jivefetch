# JiveFetch v0.3.1

日期：2026-09-05

此维护版本提高桌面下载引擎发现与已认证 YouTube 下载的可靠性，并用可操作的说明
替代通用错误。

## 亮点

- 在检测到的 `yt-dlp` 与 FFmpeg 版本旁显示 JiveFetch 版本。
- 从应用数据目录而不是受保护的 Downloads 文件夹探测引擎版本，避免 macOS 权限竞态
  错误地报告找不到 Homebrew `yt-dlp`。
- 保持精简的跨平台子进程环境，同时向 `PATH` 加入标准软件包管理器目录和 Deno 用户
  目录。通过 Finder 启动的 JiveFetch 现在能让 `yt-dlp` 使用 Homebrew Deno 处理当前
  YouTube JavaScript challenge。
- 对浏览器 Cookie、认证、媒体不可用、频率限制、HTTP 403、格式、网络和文件系统错误
  进行分类，不保存原始引擎输出或 signed URL。
- 进程退出后读取剩余输出，避免遗漏短时错误。
- 以英语、俄语和简体中文记录 macOS、Windows 与 Linux 上 `yt-dlp`、FFmpeg、Deno
  的安装方法。
- 说明为什么替换 ad-hoc 签名的 macOS 构建后可能需要重新授予 Downloads 或完全磁盘
  访问权限，以及何时会出现 Chrome Safe Storage 提示。

## 已验证的 macOS 场景

本地安装构建检测到 `yt-dlp` 2026.07.04、FFmpeg 8.1.2 和 Deno 2.9.4。选择 Chrome 后，
`yt-dlp` 成功读取浏览器 Cookie，通过 Deno 解决 YouTube JavaScript challenge，选择
媒体流并开始下载。

## 在 macOS 上安装

Apple Silicon DMG 仍未签名且未 notarize。请先验证 checksum，再按照
[macOS 安装说明](../macos-installation.zh-CN.md)操作。

## 兼容性与限制

此版本使用本机安装的 `yt-dlp`、FFmpeg 和 Deno。软件包尚未签名或 notarize，也未包含
managed sidecar。请参阅[打包限制](../packaging.zh-CN.md)与[安全模型](../security.zh-CN.md)。

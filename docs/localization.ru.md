# Политика локализации

## Языки

- `en` — английский, обязательный язык первого запуска и source locale.
- `ru` — русский.
- `zh-CN` — упрощённый китайский.

Приложение не подменяет первый EN системной локалью. После явного выбора язык
сохраняется локально и восстанавливается при запуске.

## Строки приложения

- Любая видимая строка имеет стабильный ключ в `src/i18n.tsx`; компоненты не содержат
  встроенный EN/RU/CN текст.
- Три словаря имеют одинаковые ключи, что контролируется TypeScript.
- Даты и числа форматируются выбранной локалью; domain values нейтральны.
- Состояния, ошибки, notifications, accessibility labels, меню, installer и updater
  входят в область перевода.
- Сырой вывод движка не выдаётся за перевод. Известные ошибки отображаются через
  локализованную модель, неизвестный вывод помечается как redacted diagnostics.
- Runtime fallback — EN, но отсутствующий committed-перевод блокирует release.

## Документация

Английский использует имя без суффикса, русский — `.ru.md`, упрощённый китайский —
`.zh-CN.md`. Локальные инструкции и память агентов не являются версионируемой
документацией продукта и исключены из проверки translation sets репозитория.

Каждый Markdown начинается ссылками на три версии. Внутренние ссылки ведут на перевод
того же языка, если он существует.

Перевод смысловой: команды, identifiers, code, states, paths и safety invariants не
искажаются. Нельзя ослаблять безопасность, заявлять отсутствующую функцию или убирать
release gate.

## Процесс изменения

1. Изменить исходный смысл и ключи UI.
2. В той же фазе обновить RU и 简体中文.
3. Проверить parity ключей, translation set и Markdown links.
4. Проверить layout с длинными русскими строками и CJK glyphs.
5. Коммитить только полный набор.

## Приёмка

- Чистое хранилище открывает приложение на EN.
- Каждый язык выбирается и переживает restart.
- Нет отсутствующих ключей.
- HTML `lang` соответствует выбору.
- Controls работают с длинными labels.
- У каждого Markdown base есть три взаимно связанных файла.
- README-команды и статус функций совпадают по смыслу во всех языках.

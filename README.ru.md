# JiveFetch

![Очередь загрузок JiveFetch](docs/assets/jivefetch-hero.png)

JiveFetch — локальное desktop-приложение для управления законными медиазагрузками.
Оно работает на macOS, Windows и Linux и использует установленные в системе `yt-dlp`
и FFmpeg.

## Что получает пользователь

- Устойчивая очередь, одновременные загрузки и общий лимит скорости.
- Живые прогресс, скорость, ETA, загруженный и общий размер.
- Выбор из видеоформатов, реально доступных у источника; по умолчанию — максимальное
  качество.
- Действия «Запустить», «Пауза», «Остановить», «Повторить», «Удалить» и «Копировать URL».
- Необязательная авторизация через cookies выбранного браузера.
- Настраиваемая папка загрузок и системная, светлая или тёмная тема.
- Интерфейс на английском, русском и упрощённом китайском; при первом запуске выбран EN.

## Как это получить

Установите `yt-dlp` и FFmpeg, затем скачайте JiveFetch для своей платформы:

- macOS: DMG для Apple Silicon (`arm64`).
- Windows: EXE или MSI для 64-битной системы (`x64`).
- Linux: AppImage или DEB для 64-битной системы (`x86_64`/`amd64`).
